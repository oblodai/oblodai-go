# Oblodai Go SDK — guide for coding agents

Module `github.com/oblodai/oblodai-go/v2` (2.0.0), Go ≥ 1.25, standard library only. The API surface
— `zz_generated_*.go`: every service, method, request and response model, enumeration and the route
table — is generated by the backend's `tools/sdkgen` from `services/core/api/openapi.json`; the rest
of the package is the hand-written runtime.

## Non-negotiables

- `zz_generated_*.go` are never edited by hand. A wrong generated file is fixed in the generator's
  Go templates (`tools/sdkgen/go/templates` in the backend) and regenerated; `make drift` fails on a
  stale file. `names.lock` pins the public names: a name that disappears is a breaking change.
- Calls: `client.<Service>.<Method>(ctx, params, opts...)` — context first, the parameters as a
  pointer to the generated request model (nil when none), then `RequestOption`s:
  `WithIdempotencyKey`, `WithRequestTimeout`, `WithRequestBudget`, `WithMaxRetries`,
  `WithRequestHeader`/`WithExtraHeaders`, `WithRequestID`, `WithRawResponse`. Optional model fields
  are pointers: `oblodai.Ptr(v)`.
- Amounts are `oblodai.Decimal` — a string type; a float does not fit, and a JSON number in an
  amount is `sdk.float_amount`. Never compare amounts with `<`; use `CompareAmounts`, `AmountsEqual`,
  `AddAmounts`, `SubtractAmounts`, `IsZeroAmount` (they take a `Decimal` or a plain string).
- **One API key** signs every gated route (`WithCredentials`, or `OBLODAI_PUBLIC_ID`/`OBLODAI_SECRET`).
  `RouteSpec.Auth` is `public` (unsigned), `key`, or `onboard` (`WithAdminToken`).
- Retry safety is `RouteSpec.Safe` (the contract's `x-retry-safe`) or a deduplicated write with a
  key; the SDK never infers it from a path or a verb. Idempotency keys are generated on
  deduplicated routes and reused across retries; a key on any other route is refused with
  `sdk.idempotency_unsupported` — except a route whose body has its own `idempotency_key` field (the
  sandbox faucet), where the option fills that field.
- Paged lists return `*List[T]` and request nothing until read: `Items()` and `ByPage()` iterate,
  `Page()` is the first page, `Pager()` a cursor, `Collect(max)` gathers.
- Long-running operations (the `LRO` table: batches, document exports) are followed with
  `client.BatchJob(id)`, `client.DocumentJob(id)` or `JobFor[T]`: `Wait` returns the terminal answer,
  `Download` the export's file.
- Models print (`%v`, `%+v`, `%#v`) their set fields with secrets as `[redacted]`; JSON is faithful.

## Errors

Every failure is `*oblodai.Error` (`errors.As` or `oblodai.AsError`); it prints as
`[code] message (request_id=…)`. Branch on `Code`. Fields: `Kind`, `Code`, `Message`, `HTTPStatus`,
`Retryable` (authoritative), `RetryAfter` (seconds), `RequestID`, `Field`, `Synthetic`, `LastCode`.
Predicates: `IsValidation`, `IsAuthentication`, `IsPermission`, `IsNotFound`, `IsConflict`,
`IsIdempotencyConflict`, `IsRateLimit`, `IsUnavailable`, `IsInternal`, `IsTransport`, `IsConfig`,
`IsContract`, `IsSignature`, `IsWebhookPayload`, `IsCode`, `IsKind`, `IsRetryable`. The core's codes
are the generated `ErrorCode` enumeration, and each method's doc comment lists the ones it can
answer with. Client codes: `sdk.missing_credentials`, `sdk.bad_config`, `sdk.bad_idempotency_key`,
`sdk.idempotency_unsupported`, `sdk.bad_envelope`, `sdk.bad_path_param`, `sdk.bad_amount`,
`sdk.float_amount`, `sdk.bad_header`, `sdk.response_too_large`, `sdk.wait_timeout`,
`transport.timeout|network|aborted|deadline`, `webhook.bad_signature|stale_timestamp|missing_header|bad_payload`.

## Webhooks

```go
import "github.com/oblodai/oblodai-go/v2/webhooks"

delivery, err := webhooks.VerifyRequest(r, webhooks.Options{Secret: os.Getenv("OBLODAI_WEBHOOK_SECRET")})
if err != nil {
	http.Error(w, "bad signature", http.StatusBadRequest) // 4xx only for a failed verification
	return
}
if delivery.IsTest { // a rehearsal delivery: signed like a live one, but no money moved
	w.WriteHeader(http.StatusOK)
	return
}
if payment := delivery.Event.Payment; payment != nil && oblodai.IsPaymentPaid(payment.Status) {
	markOrderPaid(payment.OrderID, delivery.EventID) // EventID is stable for one state
}
w.WriteHeader(http.StatusOK)
```

Order of checks: headers → HMAC (current secret, then `PreviousSecret`) → freshness → body. Answer
4xx to `IsSignature`, 5xx to `IsWebhookPayload`. `delivery.Event` has one typed body (`Payment`,
`Payout`, `Wallet`, `Conversion`), or none for a kind this release does not model (`IsKnown()`).
Deduplicate on `delivery.EventID`; `webhooks.IsStale(event, lastSequence)` drops out-of-order events.

## Working in this repository

```bash
make ci      # everything below, in the order that fails fastest
make drift   # zz_generated_*.go against the backend's generator (OBLODAI_BACKEND)
make test    # go test -race ./... (conformance runs when OBLODAI_BACKEND is set)
```

- Tests live next to what they test. `conformance_test.go` (and `webhooks/conformance_test.go`)
  run the backend's shared scenarios; `sweep_test.go` calls every generated method once;
  `readme_test.go` holds the documentation's Go code, runs it, and fails when a document drifts.
- A fix without a test that fails before it is not finished.
